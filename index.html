03 / WHY MALBIT

말빛이 선택한 방식.

기록 업무를 클라우드 업로드나 여러 도구 사이의 이동에만 의존하지 않도록 설계했습니다.

01 / LOCAL FIRST

내 PC에서 실행하는 AI

지원하는 모델을 설치하면 음성 인식과 일부 문서 처리를 PC에서 실행할 수 있습니다. 매번 음성 파일을 외부 서버로 전송해야 하는 작업 방식과 달리, 네트워크 의존을 줄이는 접근입니다.

02 / ONE WORKSPACE

변환부터 보관까지, 한 작업 공간

실시간 자막과 파일 변환, 화자·자막 편집, AI 요약·번역, 결과 검색을 연결합니다. 도구마다 파일을 옮기거나 작업 문맥을 다시 찾는 수고를 줄이는 것이 목표입니다.

03 / EDITABLE RESULTS

AI 결과를 그대로 두지 않도록

자막의 시간·화자·문장을 확인하고 수정하며, 기록과 요약을 다시 검색할 수 있습니다. 자동 변환의 결과를 사람이 검토하고 완성하는 경험에 초점을 맞췄습니다.

04 / UNDER THE HOOD

기술을 드러내되,
사용은 단순하게.

모델 실행, 편집 화면, 검색 인덱스는 각각 목적에 맞게 구성했습니다. 사용자는 복잡한 기술보다 자신의 기록과 결과에 집중할 수 있도록 설계하고 있습니다.

아래는 개발 중인 기술 구성입니다. 모델·PC 사양·설정·배포 버전에 따라 지원 범위가 달라질 수 있으며, 모델 설치나 일부 연결·라이선스 기능에는 인터넷이 필요할 수 있습니다.

STT 01

Whisper + OpenVINO

기본 파일 음성 인식은 Whisper 모델과 OpenVINO 실행 경로를 사용합니다. 지원되는 환경에서 CPU·Intel GPU 처리를 선택할 수 있으며 NVIDIA CUDA 경로는 선택적·실험적으로 개발 중입니다.

LOCAL LLM 02

GGUF · llama.cpp · OpenVINO

요약 등 후속 AI 문서 작업을 위해 로컬 모델 실행 경로를 분리합니다. 모델과 실행 장치, 설치 상태에 따라 사용할 수 있는 기능이 달라집니다.

SEARCH 03

SQLite FTS5

파일명, 전사 내용, 요약을 로컬 검색 인덱스로 관리하고 필요한 기록과 자막 구간을 찾을 수 있도록 합니다.

DESKTOP UI 04

Python · PySide6 / QML

작업별 패널과 타임라인, 편집 상태를 Windows 데스크톱에 맞춰 구성합니다. 반복 작업을 줄이고 수정 과정이 눈에 보이는 인터페이스를 지향합니다.

05 / ABOUT MALBIT

기록을 더 쉽게 다루기 위해.

말빛은 로컬 실행의 선택권과 편집 가능한 결과, 찾기 쉬운 기록 보관을 함께 추구합니다. 모델의 내부 동작보다 기록을 듣고, 고치고, 다시 활용하는 일이 쉬워지도록 Windows 사용 경험을 다듬고 있습니다.

현재 개발 및 검증 단계입니다. 기능 제공 범위와 지원 환경은 정식 출시 시 안내될 수 있습니다. 로컬 AI 처리 지원 여부는 모델과 기능 설정에 따라 달라집니다.
